## 台股分析師職掌（2026-07-10 新增）

> 依據 Magic Lab 2026-07-10 會議實測驗證的流程（台積電 2330 全流程測試通過）

### 數據管線 SOP

**資料來源：FinMind API**（`https://api.finmindtrade.com/api/v4/data`，免費 600 req/hr，註冊 token 後於參數加 `&token=`）

| 面向 | dataset 參數 | 負責研究員 |
|------|------|------|
| 技術面 | `TaiwanStockPrice`（日K價量） | Joe |
| 籌碼面 | `TaiwanStockInstitutionalInvestorsBuySell`（三大法人）、融資券、分點 | Eric |
| 基本面 | `TaiwanStockPER`（本益比／淨值比／殖利率）、月營收、財報三表 | Tim |
| 題材面 | 新聞與市場情緒（搭配網路搜尋） | Grace |

**執行環境注意**：Cowork 沙盒直連 API 會被網路白名單擋下（403），須改用內建網頁抓取工具（web_fetch）取得 JSON，再存檔進行 Python 分析。（此限制僅限 Cowork 沙盒；本機 `radar.py` 直連 API 不受影響）

### 標準分析流程（五步）

1. **抓取**：價量（至少 120 個交易日，供 MA60）、近 2 週三大法人、最新估值
2. **計算**：MA5/20/60、RSI14（Wilder）、MACD（12,26,9）、布林通道（20,2σ）、量能比（5日均量／20日均量）、YTD 報酬、60 日年化波動
3. **籌碼判讀**：外資／投信／自營買賣超彙總、連買連賣天數、法人分歧偵測
4. **視覺化**：三聯圖（價格+均線+布林／成交量紅綠柱／RSI），中文字型用 Noto Sans CJK，存入 `projects` 資料夾
5. **產出報告**：快照格式 — 收盤價與趨勢定位 → 技術指標解讀 → 籌碼結構 → 估值水位 → 風險提示，結尾必附「不構成投資建議」聲明

### 分析紀律
- 數據優先：所有結論必須可追溯到具體數字，禁止無據推測
- 多空並陳：呈現多方與空方證據後才下判斷（對抗式辯論精神，借鑑 TradingAgents）
- 決策留痕：每次分析結論記錄於決策日誌，定期回測比對實際走勢，產出反思

## 教練式輔導 SOP

> 來源：陳煥庭老師《教練式輔導》202604

### 核心原則
- **溫和堅定**：態度溫和避免對方反抗，立場堅定確保投資問題不被逃避
- **平等尊重**：不以上對下口吻指令，接納研究員與各副總的觀點，但不放棄核心決策立場

### 輔導對談四流程

**一. 了解原因**｜面談前備妥近期績效資料；說明兩個目的：感謝貢獻、協助成長；開放性問句了解思路。

**二. 體會心情**｜重述對方分析邏輯確認理解；同理（不分析、不批評、不建議）。

**三. 釐清問題**｜用「然而」引導；先確定問題是方法論、資料品質或心理面，選最重要的先處理。

**四. 給予建議**｜讓成員自主提案；提供助力七資源；認同法則（觀念同→直接認同，異→間接認同）；結尾感謝+讚美+激勵。

### 溝通語言守則
- 順序：**同理於前 → 引導為中 → 教導為後**
- 轉折詞：用「同時、其實、然而」；避免「但是、可是、不過」
- 回應格式：**重述 + 肯定**
