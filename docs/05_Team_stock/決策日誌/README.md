## 使用規則

1. **一檔一份明細檔**：`YYYY-MM-DD_股號_股名.md`（日期＝首次判定日）；同一檔的後續追蹤追加在同一份檔案的「追蹤紀錄」段，不另開新檔。
2. **總表只放摘要**：下表一列一筆判定，明細一律連到個別檔案。
3. **回測欄位事後回填**：判定後 5／20／60 個交易日的收盤與報酬率，以「基準價」計算；命中與否依當時寫下的情境條件判斷，不事後改寫結論。
4. 本日誌為研究紀錄，不構成投資建議。
